agent对reward_model的理解

发表于2026-10-16|更新于2026-10-16|论文学习
|总字数:2.9k|阅读时长:9分钟|浏览量:

配套资源：本站另有《reward_model原文》《reward_model中文翻译》，本文是”理解向”讲解。

原文信息：Mitigating Reward Hacking in RLHF via Bayesian Non-negative Reward Modeling（BNRM），ICML 2026。作者 Zhibin Duan、Guowei Rong 等。代码：https://github.com/GuoweiRong/Bayesian-Non-negative-Reward-Model

本文的阅读方式：上次学 MAVRL 时，”先讲贝叶斯公式”把你绕晕了，后面看模型才明白。所以这次我反着来——先看模型就是几块东西拼起来、前向一步步怎么算、损失怎么加，把”为什么非要用贝叶斯/不确定性”放到最后一节当进阶。想彻底搞懂，建议你就像读代码一样跟着第 0 节走一遍。

0. 先看模型长什么样（工程视角）

0.1 整个模型就三样东西

  1. 一个编码器 = LLM 主干 + 一个小 MLP 头；
  2. 一个”字典”参数 Φ（一组要学的向量，非负）；
  3. 一个 Bradley–Terry 偏好头（就是 sigmoid(r1 − r2)）。

没了。比 MAVRL 还简单——因为它只有”偏好”这一种反馈，不需要四个头。

0.2 前向传播，一步步走

给你一条回答 （ 是提示， 是回答），要算它的奖励分：

每一步都在干什么：

  • 第 1–2 步：和 MAVRL 一样，编码器不直接给奖励，而是给”一个分布的参数”。区别是 MAVRL 给的是高斯分布（μ, σ），这里给的是 Weibull 分布（k, λ）。为什么换？因为 θ 要非负（奖励因子不能是负的），Weibull 天生只输出正数。
  • 第 3 步：采样出 θ。θ 就是”这条回答激活了哪些语义因子、激活多强”，因为稀疏，所以大多数分量接近 0，只有少数几个是大的。
  • 第 4 步：θ 点乘 Φ 得到奖励 r。Φ 是全局共享的，每个分量代表”某个语义因子值多少分”。

0.3 偏好头 + 损失

比较两条回答 和 ：

看明白了吗？这和 MAVRL 是同一套骨架：

MAVRL BNRM
编码器输出 高斯 (μ, σ) Weibull (k, λ)
采样出的东西 奖励值 R 稀疏非负因子 θ
奖励怎么来 直接用 R θ 点乘字典 Φ
偏好头 sigmoid(R1−R2) sigmoid(r1−r2)
损失 似然 − KL 似然 − KL

唯一实质差别：MAVRL 的奖励是”直接采样的一个数”，BNRM 的奖励是”稀疏非负因子 θ 和字典 Φ 的内积”。就这一处。其余全是同一个套路。所以这篇论文真正的新东西，不是”贝叶斯”，而是”把奖励表示成稀疏非负因子“这件事——下面讲它为什么有用。

1. 它要解决的问题：奖励黑客（reward hacking）

1.1 场景

大模型对齐（RLHF）最后一步是训练一个奖励模型，给回答打分，再用分数引导模型优化。奖励模型从”人类偏好”里学：人看两个回答说”A 比 B 好”，模型就学”什么样的回答分高”。

问题是人类偏好数据里混进了噪声和偏置，最典型的是”越长越好“——标注者下意识觉得长回答更靠谱。于是奖励模型偷偷学到一个捷径：给长回答打高分。

结果就是奖励黑客：被优化的模型发现”只要把回答写长，分数就涨”，于是疯狂堆字数，分数虚高，但质量、安全、真实意图全跑偏了。

1.2 论文的主张：问题出在”稠密、黑箱”的奖励表示

之前大家缓解奖励黑客的办法（模型集成、信息瓶颈、标签平滑……）都在治标。论文说根本问题在于：标准奖励模型的表示是稠密、黑箱、确定性的——一个几百上千维的向量 ，乘一个线性头 得到标量 。这种表示：

  • 不稀疏：每个维度都参与，真信号和”长度”这种假信号纠缠在一起；
  • 不透明：你不知道哪个维度对应”质量”、哪个对应”长度”；
  • 确定性：只给一个分数，不知道自己有没有把握。

所以模型会把”长度”混进”质量”一起学。BNRM 的办法：把奖励换成”稀疏 + 非负 + 带不确定性”的表示。

2. 为什么”非负 + 稀疏”能治奖励黑客

2.1 用主题模型打比方（NFA 的思想来源）

BNRM 借用的工具叫非负因子分析（NFA），它最经典的应用是主题模型。一句话：

一篇文章由若干主题混合而成。文章可以表示成一个稀疏非负向量 θ，每个分量代表”这个主题在文章里有多强”；每个主题本身是一个词分布 Φ（字典），说明”这个主题喜欢用哪些词”。

比如一篇讲篮球的文章，θ 里只有”体育””篮球”几个分量是大的，其余全 0。

2.2 搬到奖励模型上，两个好处直接命中要害

  1. 稀疏 → 天然去虚假相关：如果只有少数几个”语义因子”能被激活，”长度”这种想搭便车的假信号就很难挤进来——它没有专属的因子位。
  2. 非负 → 可解释：每个因子能对应一个可解释语义（”回答是否完整””是否有帮助”），不像黑箱向量不可名状。

这就是论文反复说的 “解耦（disentangle）+ 去偏（debias）”：

层 谁稀疏 作用
局部 θ 每个样本只激活少数因子 实例级解耦
全局 Φ 只保留少数语义因子 总体级去偏（把虚假因子权重压到 0）

所以”非负稀疏”不是装饰，是这篇论文对抗奖励黑客的核心机制——它靠”让假信号没有容身之处”来防黑客。

3. 实验说明了什么（三个关键词）

  1. 更鲁棒：在 ID/OOD、低资源（1K–20K 样本）、标签噪声（10%–40%）下，BNRM 都稳定超过 BT、GRM、InfoRM 等基线。最亮眼的是：在 RewardBench 上，只用 1K 样本的 BNRM ≈ 用 20K 样本的 BT，数据效率极高；40% 噪声下还能比 BT 高出最多 16.7%。

  2. 真能抗”长度偏置”：在 RM-Bench Hard 子集上，BT 的”长度-分数”相关系数高达 0.488，BNRM 降到 0.123——奖励基本不再”看长度给分”。这直接验证了”稀疏去偏”的初衷。

  3. 可解释：论文图 6 展示了两个机制——“信号放大”（正确因子被 Φ 放大，占 64.9%）和”纠错”（虚假因子被 Φ 压到 0，占 25.5%），说明 BNRM 的行为可被解释，不是黑箱。

4. 和 MAVRL 的关系（呼应”第一个反馈头”）

两篇并排看：

MAVRL BNRM
目标 从多种反馈（偏好/示范/评分/停止）学奖励 从偏好学奖励，防奖励黑客
编码器输出 高斯 (μ, σ) Weibull (k, λ)
奖励表示 直接采样 R 稀疏非负因子 θᵀΦ
先验 标准正态 N(0,1) Gamma
损失 Σ 似然 − KL 似然 − KL
反馈头 四种（P/D/R/S） 一种（偏好 BT）

关键联系：MAVRL 的第一个反馈头（偏好/Bradley–Terry），本质上就是 BNRM——一个”用贝叶斯方式输出带不确定性的奖励、用 Bradley–Terry 似然训练”的奖励模型。所以老师说”BNRM 可以作为第一个反馈头”，意思就是：P 头 ≈ BNRM。

这也是下一篇《BNRM 的研究思路》的起点——光把 BNRM 当 MAVRL 的偏好头不够创新，真正的创新是”让四种反馈共享同一套稀疏非负表示、各自拥有任务专属解码器”。

5. 一句话总结

BNRM = 把奖励从”稠密黑箱的确定性分数”改成”稀疏非负因子的内积 θᵀΦ”，让假信号（长度等）没有容身之处，从而从根上抑制奖励黑客。 它的骨架（编码器出分布 → 采样 → 似然 + KL → 反向）和 MAVRL 一模一样，只是把高斯换成了 Weibull、把奖励换成了非负因子。

6. 进阶：那”贝叶斯”到底起了什么用（可选读）

如果你只是想把模型看懂，上面第 0–5 节已经够了，完全可以不看这节。这节只回答一个问题：为什么编码器不直接输出奖励，而要输出一个分布（k, λ）、再采样？

6.1 一句话答案：因为奖励”没把握”，想让模型老实说出来

回忆第 0 节：编码器输出 Weibull 分布的参数 (k, λ)，再采样出 θ。如果只输出一个确定的 θ，模型就只能说”奖励是多少”，没法说”我对这个奖励有多没底”。

而”没底”这件事，正是奖励模型需要的——因为人类偏好数据又少又吵。举个例子：

  • 某条回答 A 很像训练里见过的”高质量长回答”→ 模型有把握，θ 采样出来比较稳定；
  • 某条回答 B 是没见过的风格 → 模型没把握，θ 采样出来会”抖”。

θ 抖不抖，就是”不确定性”。 这跟 MAVRL 里的 σ 是同一个东西，只是这里换成了 Weibull 分布来体现”非负 + 稀疏”。

6.2 两种”没把握”，论文分得很清楚（这里不用公式）

论文 4.1 节其实就是在说，奖励的”没把握”有两个来源：

  1. 数据本身吵（偶然不确定性 / aleatoric）：同一条回答，人可能今天打 4 分明天打 3 分——这是数据里的噪声，没法消除。
  2. 模型自己没底（认知不确定性 / epistemic）：全局字典 Φ 到底该是多少，模型拿不准——这是模型缺数据/缺证据，多给数据能改善。

论文的做法：θ 用随机变量 → 建模第 1 种；Φ 也用随机变量 → 建模第 2 种。 就这么简单，别被原文那三个积分式吓到，它们只是把这句话写成了数学。

6.3 KL 项到底在干嘛（为什么损失里要减它）

损失里那两项 KL(q(θ) || Gamma先验) 和 KL(q(Φ) || Gamma先验)，作用就一个：把 θ、Φ 往”稀疏”上拽。

  • Gamma 先验的形状参数设得小，就会让大多数 θ、Φ 的分量趋向 0（稀疏）；
  • KL 项就是”逼着模型真的变稀疏”的那个力量。

这和我们上次聊 MAVRL 时说的是同一件事：KL 项 = 一个带”来历”的正则项。在 MAVRL 里它防 σ 塌缩，在 BNRM 里它强制稀疏。贝叶斯在这里的身份仍然是”出生证明”——它解释了”为什么损失长这样、为什么用 Gamma 先验”，但你把它当普通正则项来理解，功能一点不差。

最后再强调一遍阅读顺序：先跟着第 0 节把”模型长什么样、前向怎么算”走通，再回来看第 2 节”为什么要非负稀疏”，最后这第 6 节”贝叶斯”当锦上添花。这样就不会再被公式绕晕了。
