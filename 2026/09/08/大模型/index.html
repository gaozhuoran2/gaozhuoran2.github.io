Transformer

词嵌入与位置编码
模型首先将输入文本拆分为一个个 Token，再通过词嵌入矩阵将每个 Token 映射为高维词向量。所谓词嵌入矩阵其实就是Token list，只不过矩阵的参数会不断更新，查表的时候直接 one-hot向量x词嵌入矩阵。词嵌入矩阵可以从零开始训练，也可以直接加载预训练好的权重，通过查表快速完成 Token 到向量的转换
词向量能够编码词汇的语义特征，且在向量空间中体现语义关联，比如说希特勒和墨索里尼的差值会跟德国和意大利相似，语义相近的词在空间中距离更近。模型没有办法读懂文字，但他可以通过这些向量展现文字的内容。
词向量的维度往往很高，比如GPT-3有12288维。词嵌入本身不包含位置信息，Transformer 会额外引入位置编码，将位置信息与词向量逐元素相加，让模型感知词汇的顺序关系

自注意力机制
词嵌入能提取单个Token的特征，但无法结合上文提取更加符合语境的特征，自注意力的作用是让每个 Token 融合所有相关 Token 的信息，输出符合上下文的向量

单头自注意力
对于每个 Token，用三个独立的投影矩阵，将词向量分别映射为三类向量

  • 查询向量 Q (Query)：代表 “我要检索什么信息”
  • 键向量 K (Key)：代表 “我包含什么可匹配的特征”
  • 值向量 V (Value)：代表 “我携带的实际语义内容”

通俗来说，每个Token会向所有Token发问（Query），我们有关系吗，即每一个Token的词嵌入向量乘以矩阵 得到查询向量 ，矩阵Q的维度往往较少。每个词向量乘以键矩阵 ，与 相同，他也会把高维向量映射到相同的低维。如果两个向量相似，就说明两个Token关系匪浅，我们用QK的点积乘来表示相关程度。得到所有Token的QK点积，即我们对Token两两之间的相关程度打了分,将得分除以 （ 为键向量维度）做缩放，保证数值稳定性。然后用softmax把得分变成0~1的概率分布，作为两两之间的相关性权重。我们取值矩阵 乘以前面的词向量，得到这个Token携带的实际语义，并用相关性权重对所有Token的V向量加权求和，得到当前 Token 的注意力输出。这一步可以形象的理解成我们将当前Token的词向量移动到了更适合当前语境的地方

同一层自注意力中，所有 Token 共享同一组 投影矩阵，他们并不是能有效预测下一个值，他们只是把某个词向量分别投影成“我想找什么”，“我是什么”，“我携带的信息是什么”。
矩阵因为太过庞大，比如GPT3就达到了 12288x12288 维，我们通过低秩分解，即把大矩阵分解成两个小矩阵乘积的形式减少参数，通过损失少量精度的形式大幅提升效率
需要注意的是，以上是双向自注意力，可访问所有位置的Token。在现在的主流大模型，如GPT中，模型不能读取未来信息，因此加入因果掩码：将当前Token之后所有位置的QK得分设为 ，softmax后对应权重变为0，实现仅关注历史与当前Token。不过在推理过程中，我们不用先算出所有Token之间的QK值，只用算出当前Token和之前的，就不需要掩码了

多头注意力
多头注意力设计多套QKV，每个单头独立计算注意力，最后将所有头的输出在维度上拼接，再通过输出矩阵 投影回原始维度。这样可以从不同角度提取注意力，得到词语间更多的信息和特征

MLP
经过多头注意力后，每个 Token 得到融合上下文的向量，我们把这个向量做一个简单的激活
具体实现为：首先通过一个线性层将向量升维（通常为原维度的 4 倍）并加偏置，经过激活函数引入非线性，再通过第二个线性层将向量降维回原始维度并加偏置

Transformer 层的完整结构

Transformer的每一层，核心是注意力 + MLP，还搭配残差连接与层归一化，这俩是深度网络稳定训练的关键，残差连接可以将模块输入与输出直接相加，缓解梯度消失，层归一化对向量做特征归一化，加速训练收敛
当前主流的一层：
输入 → LayerNorm → 多头自注意力 → 残差连接 → LayerNorm → MLP → 残差连接 → 输出

微调大模型

LLM 先预训练，用Transformer架构训练海量文本，训练结束后他可以根据前面的词预测文本。不过预训练的大模型可以补全文本，但没办法听懂指令，比如说我们问怎么做番茄炒蛋，他会顺着我们给他说的话往下说而不是选择回答问题。

我们希望能对每一个回答进行打分，但是打分很主观，不太好弄，我们退而求其次，每次比较两个模型的好坏，将比较好坏的结果作为输入给奖励模型。奖励模型本质上也是一个大模型，训练好后做的事情就是对于每一个回答打分
