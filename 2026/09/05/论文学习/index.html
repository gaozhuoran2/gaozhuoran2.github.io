编码器

编码器就是最正常的神经网络，几个全连接层，输入是一批 (s,a)，即一批 6 维向量。编码器会输出 μ 和 logσ，其中 μ 和 logσ 都是张量（每个 s,a 都生成一个）。这里之所以输出方差的 log 主要是要保证方差非负，因为神经网络刚开始完全可能输出负的方差，而先输出对数后面取指数肯定就是正数了

我们要干的事情就是给每个 (s,a) 打分，编码器输出的这个 R 就很合适，但是人类给的反馈可不是一步步给的，他只会给出对于一整条轨迹，即一堆 (s,a) 拼到一块后的轨迹的反馈

理解背后的数学原理

完整的看完他的模型之后我觉得这个论文的比重有点问题，他把不占太多比重（至少我感觉是这样）的数学证明写的超级长，超级复杂，让人第一眼看了就蒙，用 ds 的话说就是“是这些论文故意（或无意）把这些词说得比它们实际更重”，实际我看完了整个模型之后哪怕是完全不看贝叶斯公式的部分也完全能把这个跑通。可能就是会对为什么编码器为什么要输出一个均值和方差而不是一个数字有疑惑，但这个可以用不确定性解释…我初读论文这块困扰了我好久好久（当然，这确实让文章看起来很高大上

当然我并不否认贝叶斯根据先验和似然求后验的整体思路跟我们干的事情不谋而合，从某种程度上说这是这个模型背后的数学基础也没错，但是论文中讲的太复杂了吧

首先解释一下为什么要弄均值和方差，即为什么编码器的输出是一个分布而不是一个值：他能看出模型哪里没学到（方差很大就是这块没学好，说明要多学这一块）；他还有正则的作用，我们认为正常应该是标准正太分布

后验：
在已经拿到反馈这个观测之后，反向推断奖励的概率分布。
后验 = 看到观测（反馈）之后得到的概率。

似然（likelihood）：

它不是 “的概率”，是给定时，观测（反馈）出现的可能性，叫似然。

先验（prior）：
在还没看反馈之前，我们对奖励本身的分布预设。
先验 = 拿到观测（反馈）之前，对的先在信念。

用贝叶斯解释这个模型就是：我们认为奖励模型开始（先验）是标准正态分布，根据反馈看他的似然（就是损失函数中第一项），然后更新他的后验（就是我们希望奖励模型最终输出的）

Mitigating Reward Hacking in RLHF via Bayesian Non-negative Reward Modeling

原文：BNRM论文
中文版：BNRM论文全文中文翻译
前置知识：Transformer基础架构和原版奖励模型

先看看这个模型长啥样

编码器由 LLM 和 MLP 构成

LLM 的输入就是提示词和 AI 的回答，输出是一个维度很高的向量 z，这个 z 向量表示 LLM 对这个回答的整体印象

然后 z 进入 MLP 网络，输出一些分布，每个分布由 构成，然后这些分布按概率取一个值，所有值构成一个向量。这一步跟 MAVRL 很像，其实就是不直接输出奖励，而是弄一个分布，让这个分布输出。这个向量 维度较低

然后有一个全局字典 ，这个也是要学的， 得出分数，然后就是正常的算损失，反向传播

模型为什么长这样

整体思路跟 MAVRL 有点像，但细节处理完全不同

LLM 提炼出的高维向量可以理解为对回答的整体印象，但是他的维度太高，而且大部分项是不为 0 的，如果效果不达预期，根本反推不了，也就是可解释性很差

于是我们用 MLP 把这个向量压缩成低维向量，这里面每个值可以理解为某个语义因子的强度。这里面的值也是跟 MAVRL 一样是根据分布输出出来的，只不过用的是 Weibull 分布

Weibull 分布

都要大于 0，x 也要大于 0

当 k 小于 1，f(x) 就类似于一个倒过来的 log 函数，当 k>1 时，f(x) 类似于往右平移之后的正态分布

我们的损失函数会让 c 大部分值趋向于 0，这样我们可以直接拿出 来看。比如过，改变输入的一些特征，看看哪个值变化的多，我们就能明白这个值可能就跟某个特征有关

全局字典 是一组可学习的参数，他表示，某个语义因子值多少分

和 都是大于 0 的，这样可以让分数不被抵消

其中，先验中 k 极小，即认为大部分都是 0

当然，贝叶斯也可以认为是模型后面的数学基础

这样能解决什么问题

训练奖励模型的时候会遇到奖励黑客的问题，比如说人类偏向于认为长的回答比较好，奖励模型就会对一些其实不怎么的，但长的回答打高分。而原来的奖励模型是黑箱，不稀疏不透明

而 BNRM 是稀疏向量，长度这种激活因子很难往进混，并且这是可解释的
